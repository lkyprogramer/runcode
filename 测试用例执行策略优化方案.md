# 在线判题系统 - 测试用例执行策略优化方案

## 问题分析

对于有几十甚至上百个测试用例的题目，如何高效执行是判题系统的核心优化点。

---

## 方案对比

### ❌ 方案一：每个测试用例独立容器

```java
for (TestCaseDTO testCase : testCases) {
    // 每次都创建新容器
    String containerId = createContainer(image);
    startContainer(containerId);

    SandboxResult result = executeTestCase(containerId, testCase);

    removeContainer(containerId);
    // 重复 100 次...
}
```

**性能分析：**
- 容器创建时间：500ms - 3s
- 100个测试用例总耗时：**50s - 300s** 😱
- Docker daemon 负载：**极高**
- 资源开销：**巨大**

**结论：完全不可行！**

---

### ✅ 方案二：单容器批量执行（推荐）

```java
// 1. 创建容器一次
String containerId = createContainer(image);
startContainer(containerId);

// 2. 编译代码（仅一次）
compileCode(containerId, code);

// 3. 循环执行所有测试用例
List<TestCaseResult> results = new ArrayList<>();
for (TestCaseDTO testCase : testCases) {

    // 在同一容器内执行，只是替换输入
    TestCaseResult result = executeInContainer(
        containerId,
        testCase.getInput(),
        testCase.getExpectedOutput()
    );

    results.add(result);

    // 策略：遇到第一个错误就停止（LeetCode 默认行为）
    if (result.getStatus() != TestCaseStatus.PASSED) {
        break;
    }
}

// 4. 清理容器
removeContainer(containerId);
```

**性能分析：**
- 容器创建时间：1s（仅一次）
- 单个测试用例执行：10ms - 100ms
- 100个测试用例总耗时：**2s - 11s** ✅
- 性能提升：**10x - 50x**

## 核心实现代码

### 方式 A：exec 命令多次执行

```java
@Component
@Slf4j
public class BatchJudgeExecutor {

    @Autowired
    private DockerClient dockerClient;

    /**
     * 在一个容器内批量执行测试用例
     */
    public List<TestCaseResult> batchExecute(
        String code,
        String language,
        List<TestCaseDTO> testCases,
        int timeLimit,
        int memoryLimit
    ) throws Exception {

        String containerId = null;
        List<TestCaseResult> results = new ArrayList<>();

        try {
            // 1. 创建容器
            containerId = createContainer(language, memoryLimit);
            dockerClient.startContainerCmd(containerId).exec();

            // 2. 写入代码文件
            writeCodeToContainer(containerId, code, language);

            // 3. 编译代码（如果需要）
            if (needsCompilation(language)) {
                CompileResult compileResult = compileInContainer(containerId, language);
                if (!compileResult.isSuccess()) {
                    throw new CompileException(compileResult.getErrorMessage());
                }
            }

            // 4. 循环执行测试用例
            for (TestCaseDTO testCase : testCases) {

                // 写入输入文件
                writeInputToContainer(containerId, testCase.getInput());

                // 执行测试用例
                TestCaseResult result = executeSingleTestCase(
                    containerId,
                    language,
                    timeLimit
                );

                // 对比输出
                result.setPassed(
                    result.getOutput().trim().equals(testCase.getExpectedOutput().trim())
                );

                results.add(result);

                // 策略 1: 遇到第一个失败就停止
                if (!result.isPassed()) {
                    log.info("测试用例失败，停止执行: testCaseId={}", testCase.getId());
                    break;
                }

                // 策略 2: 如果题目设置了"显示所有测试用例"，则继续
                // if (question.isShowAllTestCases()) { continue; }
            }

            return results;

        } finally {
            // 5. 清理容器
            if (containerId != null) {
                try {
                    dockerClient.removeContainerCmd(containerId)
                        .withForce(true)
                        .exec();
                } catch (Exception e) {
                    log.error("清理容器失败: {}", containerId, e);
                }
            }
        }
    }

    /**
     * 写入代码到容器
     */
    private void writeCodeToContainer(String containerId, String code, String language) {
        String fileName = getFileName(language);  // Main.java, code.py, code.cpp
        String base64Code = Base64.getEncoder().encodeToString(code.getBytes());

        ExecCreateCmdResponse exec = dockerClient.execCreateCmd(containerId)
            .withCmd("bash", "-c",
                String.format("echo '%s' | base64 -d > %s", base64Code, fileName))
            .exec();

        dockerClient.execStartCmd(exec.getId()).exec(new ExecStartResultCallback()).awaitCompletion();
    }

    /**
     * 编译代码
     */
    private CompileResult compileInContainer(String containerId, String language) {
        String compileCmd = getCompileCommand(language);
        // javac Main.java
        // g++ -O2 -std=c++17 code.cpp -o code

        ExecCreateCmdResponse exec = dockerClient.execCreateCmd(containerId)
            .withCmd("bash", "-c", compileCmd)
            .withAttachStdout(true)
            .withAttachStderr(true)
            .exec();

        ByteArrayOutputStream stdout = new ByteArrayOutputStream();
        ByteArrayOutputStream stderr = new ByteArrayOutputStream();

        try {
            dockerClient.execStartCmd(exec.getId())
                .exec(new ExecStartResultCallback(stdout, stderr))
                .awaitCompletion();

            String error = stderr.toString();

            return CompileResult.builder()
                .success(error.isEmpty())
                .errorMessage(error)
                .build();

        } catch (InterruptedException e) {
            return CompileResult.builder()
                .success(false)
                .errorMessage("编译超时")
                .build();
        }
    }

    /**
     * 写入测试输入
     */
    private void writeInputToContainer(String containerId, String input) {
        String base64Input = Base64.getEncoder().encodeToString(input.getBytes());

        ExecCreateCmdResponse exec = dockerClient.execCreateCmd(containerId)
            .withCmd("bash", "-c",
                String.format("echo '%s' | base64 -d > input.txt", base64Input))
            .exec();

        dockerClient.execStartCmd(exec.getId()).exec(new ExecStartResultCallback()).awaitCompletion();
    }

    /**
     * 执行单个测试用例
     */
    private TestCaseResult executeSingleTestCase(
        String containerId,
        String language,
        int timeLimit
    ) throws Exception {

        String runCmd = getRunCommand(language);
        // java Main < input.txt
        // python3 code.py < input.txt
        // ./code < input.txt

        ExecCreateCmdResponse exec = dockerClient.execCreateCmd(containerId)
            .withCmd("bash", "-c",
                String.format("timeout %ds %s", timeLimit / 1000, runCmd))
            .withAttachStdout(true)
            .withAttachStderr(true)
            .exec();

        ByteArrayOutputStream stdout = new ByteArrayOutputStream();
        ByteArrayOutputStream stderr = new ByteArrayOutputStream();

        long startTime = System.currentTimeMillis();

        try {
            dockerClient.execStartCmd(exec.getId())
                .exec(new ExecStartResultCallback(stdout, stderr))
                .awaitCompletion(timeLimit + 1000, TimeUnit.MILLISECONDS);

            long executionTime = System.currentTimeMillis() - startTime;

            // 获取内存使用情况
            long memoryUsage = getMemoryUsage(containerId);

            String output = stdout.toString();
            String error = stderr.toString();

            return TestCaseResult.builder()
                .output(output)
                .errorMessage(error)
                .executionTime(executionTime)
                .memoryUsage(memoryUsage)
                .build();

        } catch (InterruptedException e) {
            throw new TimeoutException("执行超时");
        }
    }

    /**
     * 获取容器内存使用
     */
    private long getMemoryUsage(String containerId) {
        try {
            Statistics stats = dockerClient.statsCmd(containerId)
                .withNoStream(true)
                .exec(new StatsCallback())
                .awaitStats();

            return stats.getMemoryStats().getUsage() / 1024; // KB
        } catch (Exception e) {
            return 0;
        }
    }

    private static class StatsCallback extends ResultCallbackTemplate<StatsCallback, Statistics> {
        private Statistics stats;

        @Override
        public void onNext(Statistics stats) {
            this.stats = stats;
        }

        public Statistics awaitStats() throws InterruptedException {
            awaitCompletion();
            return stats;
        }
    }
}
```

### 方式 B：脚本化批量执行（更高效）

```java
/**
 * 生成一次性执行所有测试用例的脚本
 * 适用于测试用例数量极多的场景（100+）
 */
public String generateBatchScript(
    String code,
    String language,
    List<TestCaseDTO> testCases
) {
    StringBuilder script = new StringBuilder();

    // 1. 写入代码
    script.append(String.format("cat > code.%s << 'EOF'\n", getFileSuffix(language)));
    script.append(code);
    script.append("\nEOF\n\n");

    // 2. 编译（如果需要）
    if (needsCompilation(language)) {
        script.append(getCompileCommand(language)).append("\n\n");
    }

    // 3. 循环执行所有测试用例
    script.append("results=()\n");
    script.append("exec_times=()\n");
    script.append("memory_usage=()\n\n");

    for (int i = 0; i < testCases.size(); i++) {
        TestCaseDTO testCase = testCases.get(i);

        script.append(String.format("# 测试用例 %d\n", i + 1));
        script.append(String.format("cat > input_%d.txt << 'EOF'\n", i));
        script.append(testCase.getInput());
        script.append("\nEOF\n\n");

        // 执行并计时
        script.append(String.format(
            "start_time=$(date +%%s%%3N)\n" +
            "output_%d=$(/usr/bin/time -v %s < input_%d.txt 2>&1)\n" +
            "end_time=$(date +%%s%%3N)\n" +
            "exec_time=$((end_time - start_time))\n" +
            "exec_times+=($exec_time)\n\n",
            i, getRunCommand(language), i
        ));

        // 保存输出
        script.append(String.format("results+=($output_%d)\n\n", i));
    }

    // 4. 输出所有结果（JSON 格式）
    script.append("echo '{\"results\": ['");
    script.append("for i in ${!results[@]}; do\n");
    script.append("  echo \"{\\\"output\\\": \\\"${results[$i]}\\\", \\\"time\\\": ${exec_times[$i]}}\"\n");
    script.append("  if [ $i -lt $((${#results[@]} - 1)) ]; then echo ','; fi\n");
    script.append("done\n");
    script.append("echo ']}'");

    return script.toString();
}

/**
 * 一次性执行所有测试用例
 */
public List<TestCaseResult> executeAllAtOnce(
    String code,
    String language,
    List<TestCaseDTO> testCases
) throws Exception {

    String script = generateBatchScript(code, language, testCases);

    String containerId = createContainer(language);
    dockerClient.startContainerCmd(containerId).exec();

    try {
        // 执行脚本
        String jsonOutput = executeScript(containerId, script);

        // 解析 JSON 结果
        JSONObject result = new JSONObject(jsonOutput);
        JSONArray results = result.getJSONArray("results");

        List<TestCaseResult> testCaseResults = new ArrayList<>();
        for (int i = 0; i < results.length(); i++) {
            JSONObject item = results.getJSONObject(i);

            TestCaseResult tcResult = TestCaseResult.builder()
                .output(item.getString("output"))
                .executionTime(item.getLong("time"))
                .passed(item.getString("output").trim()
                    .equals(testCases.get(i).getExpectedOutput().trim()))
                .build();

            testCaseResults.add(tcResult);
        }

        return testCaseResults;

    } finally {
        dockerClient.removeContainerCmd(containerId).withForce(true).exec();
    }
}
```

## 执行策略选择

### 策略 1: 快速失败（LeetCode 默认）

```java
for (TestCaseDTO testCase : testCases) {
    TestCaseResult result = execute(testCase);

    if (!result.isPassed()) {
        // 遇到第一个失败立即停止
        return SubmissionStatus.WRONG_ANSWER;
    }
}
return SubmissionStatus.ACCEPTED;
```

**适用场景：**
- ✅ 大部分在线判题系统
- ✅ 提高判题效率
- ✅ 快速反馈错误

**优点：**
- 节省时间（失败后不再执行）
- 减少资源消耗
- 用户体验好（快速知道结果）

### 策略 2: 执行所有测试用例

```java
int passedCount = 0;
for (TestCaseDTO testCase : testCases) {
    TestCaseResult result = execute(testCase);

    if (result.isPassed()) {
        passedCount++;
    }

    // 继续执行，不停止
}

// 计算得分
double score = (double) passedCount / testCases.size() * 100;
return score;
```

**适用场景：**
- ✅ 部分通过给分制（如 Codeforces）
- ✅ 调试模式（显示所有失败用例）
- ✅ 教学系统

**缺点：**
- 耗时更长
- 资源消耗更大

### 策略 3: 混合策略（推荐）

```java
// 配置项
boolean showAllTestCases = question.isShowAllTestCases();
boolean isDebugMode = request.isDebugMode();

int passedCount = 0;
List<TestCaseResult> failedCases = new ArrayList<>();

for (TestCaseDTO testCase : testCases) {
    TestCaseResult result = execute(testCase);

    if (result.isPassed()) {
        passedCount++;
    } else {
        failedCases.add(result);

        // 根据配置决定是否停止
        if (!showAllTestCases && !isDebugMode) {
            break;  // 快速失败
        }
    }
}

// 返回详细信息
return SubmissionResult.builder()
    .status(passedCount == testCases.size() ? ACCEPTED : WRONG_ANSWER)
    .passedCount(passedCount)
    .totalCount(testCases.size())
    .failedCases(isDebugMode ? failedCases : failedCases.subList(0, 1))  // 调试模式显示所有失败
    .build();
```

## 状态污染问题及解决

### 问题：全局变量污染

```python
# 用户代码可能有全局变量
count = 0

def solution(nums):
    global count
    count += 1  # 每次执行都累加
    return count

# 测试用例 1: 期望输出 1，实际输出 1 ✅
# 测试用例 2: 期望输出 1，实际输出 2 ❌  (被污染了！)
```

### 解决方案 A: 进程隔离

```java
/**
 * 每个测试用例在新进程中执行
 * 避免全局变量污染
 */
private String executeInNewProcess(String containerId, String command) {

    ExecCreateCmdResponse exec = dockerClient.execCreateCmd(containerId)
        .withCmd("bash", "-c", command)
        .withAttachStdout(true)
        .withAttachStderr(true)
        .exec();

    // 每次 exec 都是新进程，不共享内存
    ByteArrayOutputStream output = new ByteArrayOutputStream();
    dockerClient.execStartCmd(exec.getId())
        .exec(new ExecStartResultCallback(output, output))
        .awaitCompletion();

    return output.toString();
}
```

**原理：**
- Docker `exec` 每次创建新进程
- 进程之间不共享内存空间
- 天然隔离全局变量

### 解决方案 C: 重启容器（最保险）

```java
/**
 * 每 N 个测试用例后重启容器
 * 平衡性能和隔离性
 */
public List<TestCaseResult> executeBatched(
    String code,
    List<TestCaseDTO> testCases,
    int batchSize
) {

    List<TestCaseResult> allResults = new ArrayList<>();

    // 分批执行
    for (int i = 0; i < testCases.size(); i += batchSize) {

        List<TestCaseDTO> batch = testCases.subList(
            i,
            Math.min(i + batchSize, testCases.size())
        );

        // 每批创建新容器
        String containerId = createContainer(...);

        List<TestCaseResult> batchResults = executeBatch(containerId, batch);
        allResults.addAll(batchResults);

        // 清理容器
        removeContainer(containerId);
    }

    return allResults;
}
```

**配置建议：**
- 简单题目：batchSize = 100（一次性执行所有）
- 复杂题目：batchSize = 20（分批执行）

## 真实场景推荐策略

### LeetCode 风格系统

```java
@Override
public SubmissionResult judge(JudgeRequest request) {

    // 1. 获取测试用例（通常 50-200 个）
    List<TestCaseDTO> testCases = getTestCases(request.getQuestionId());

    // 2. 创建单个容器
    String containerId = createContainer(request.getLanguage());

    try {
        // 3. 编译代码
        compile(containerId, request.getCode());

        // 4. 批量执行（快速失败模式）
        int passedCount = 0;
        TestCaseResult firstFailure = null;
        long maxTime = 0;
        long maxMemory = 0;

        for (TestCaseDTO testCase : testCases) {
            TestCaseResult result = executeTestCase(containerId, testCase);

            maxTime = Math.max(maxTime, result.getExecutionTime());
            maxMemory = Math.max(maxMemory, result.getMemoryUsage());

            if (result.isPassed()) {
                passedCount++;
            } else {
                firstFailure = result;
                break;  // 遇到第一个失败就停止
            }
        }

        // 5. 返回结果
        return SubmissionResult.builder()
            .status(passedCount == testCases.size() ? ACCEPTED : WRONG_ANSWER)
            .passedTestCases(passedCount)
            .totalTestCases(testCases.size())
            .executionTime(maxTime)
            .memoryUsage(maxMemory)
            .firstFailedCase(firstFailure)  // 只返回第一个失败的用例
            .build();

    } finally {
        removeContainer(containerId);
    }
}
```

@Override
public SubmissionResult judgeWithSPJ(JudgeRequest request) {

    String containerId = createContainer(request.getLanguage());

    try {
        // 1. 编译用户代码
        compile(containerId, request.getCode());

        // 2. 编译 SPJ 程序（C++ 实现）
        String spjContainerId = createContainer("cpp");
        compile(spjContainerId, question.getSpjCode());

        int passedCount = 0;

        for (TestCaseDTO testCase : testCases) {
            // 3. 运行用户程序
            String userOutput = execute(containerId, testCase.getInput());

            // 4. 运行 SPJ 程序校验
            // SPJ 输入：测试用例输入 + 用户输出 + 标准输出
            String spjInput = testCase.getInput() + "\n" +
                             userOutput + "\n" +
                             testCase.getExpectedOutput();

            String spjResult = execute(spjContainerId, spjInput);

            // 5. SPJ 返回 0 表示正确，1 表示错误
            if ("0".equals(spjResult.trim())) {
                passedCount++;
            }
        }

        return buildResult(passedCount, testCases.size());

    } finally {
        removeContainer(containerId);
        removeContainer(spjContainerId);
    }
}

## 最佳实践总结

### ✅ 推荐做法

1. **默认策略：单容器批量执行**
   - 创建容器 → 编译 → 循环执行测试用例 → 清理
   - 性能最优，资源消耗最低

2. **快速失败模式**
   - 遇到第一个错误立即停止
   - 适合 90% 的场景

3. **使用 Docker exec**
   - 每个测试用例用新进程执行
   - 天然避免状态污染

4. **合理的超时控制**
   - 单个测试用例超时：题目限制（如 1s）
   - 整体超时：测试用例数 × 单个超时 × 1.5

5. **内存监控**
   - 执行后立即读取容器统计信息
   - 取所有测试用例中的最大值

### ❌ 避免做法

1. ❌ 每个测试用例创建独立容器
2. ❌ 不做任何隔离（全局变量污染）
3. ❌ 不限制执行时间（死循环风险）
4. ❌ 不清理临时容器（资源泄漏）

## 总结

**对于 100 个测试用例的题目：**

✅ **正确做法**：创建 **1 个容器**，内部循环执行 100 次
❌ **错误做法**：创建 **100 个容器**，每次执行 1 次

**性能差距：40 倍以上！**

关键在于理解：
- Docker 容器创建是**重操作**（秒级）
- 容器内执行命令是**轻操作**（毫秒级）
- 用 `docker exec` 可以在同一容器内多次执行，互不干扰
